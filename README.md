# TechSaúde

O **TechSaúde** é um aplicativo web de apoio ao dia a dia de pessoas idosas — e de quem ajuda elas no celular. Não é só um app de saúde: a proposta é ser um acompanhante digital simples para rotinas que normalmente pedem ajuda de outra pessoa.

## Por que pensamos nele

Com frequência precisamos parar o que estamos fazendo para ensinar um parente idoso (e às vezes até um desconhecido) a mexer no celular: abrir um app, lembrar um remédio, entender um comprovante, fazer um Pix. Essas tarefas são simples para quem já nasceu no digital e cansativas para quem não nasceu. Pensamos no TechSaúde para concentrar isso numa tela grande, com poucos passos, para a pessoa conseguir sozinha o máximo possível.

## O que ele faz

O aplicativo reúne, no mesmo lugar:

- cuidados de saúde (consultas, lembretes, medicamentos e calendário);
- rotinas do cotidiano, como apoio para fazer um Pix;
- estímulos de cognição, com mini jogos de memória;
- atalhos de ajuda, como comando de voz, dicas úteis e emergência.

A ideia é reduzir a dependência de um familiar a cada tarefa no celular, sem deixar a pessoa desassistida.

## Como acessar

1. Entre no repositório no GitHub e clique em **Code → Download ZIP**, ou clone o projeto.
2. Extraia a pasta e abra o diretório `app-techsaude`.
3. Abra o arquivo `index.html` no navegador (dois cliques ou arrastar o arquivo para o Chrome/Edge).

A partir daí é só criar a conta ou fazer login. A tela inicial (`home.html`) é o menu do aplicativo.

> Se estiver testando só os arquivos da pasta, comece sempre pelo `index.html`.
